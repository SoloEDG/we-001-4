# 灰烬渡口

安装：`npm ci`

本地启动：`npm run dev`，打开终端显示的地址。

Docker 启动：`docker compose up --build`，访问 http://localhost:18071。

## 压力机关与连锁陷阱

在左侧「压力机关」面板选择模板并配置参数（推动方向/格数、目标地形与半径、
状态与半径、伤害值），点击空地即可部署；拆除模式或地图格右键可移除机关。
机关仅能部署在非断崖、无角色占用、且未重复部署的格子上。

结算规则：

- 角色沿移动路径逐格移动，进入未消耗机关所在格即触发，机关一次性消耗。
- 效果支持：改变邻格地形、施加状态（迟缓/灼烧/防御）、沿方向推动、直接伤害。
- 两个机关互相触发时，一次行动内每个机关最多触发一次，从而自动停止循环。
- 推动最多移动配置格数；遇断崖、地图边界或其他角色阻挡时，停在最后一个合法格。
- 角色在连锁中死亡立即中止剩余路程与后续连锁。
- 整条连锁作为一次不可拆分的行动提交（先草稿结算、成功后原子落库）；
  存档失败会连同战斗状态与事件日志整体回滚，不会留下半条连锁。
- 机关消耗状态写入战斗快照，重载页面后仍保持；危险预览、移动可达区与
  技能目标均随最新结算结果更新。
- 回放中每个事件记录完整的连锁跳数，逐步标注来源机关，并高亮每次连锁的来源格。

## 校验

- 类型检查与构建：`npm run typecheck`、`npm run build`
- 机关引擎语义测试：`npx esbuild scripts/verify-traps.ts --bundle --platform=node --format=esm --outfile=/tmp/v.mjs && node /tmp/v.mjs`
- 编排层端到端（原子提交/回滚/回放）测试：`node scripts/bundle-tests.mjs && node /tmp/verify-workspace.mjs`
